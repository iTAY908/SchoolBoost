# 🎒 SchoolBoost — בוט טלגרם לניהול לימודים

בוט טלגרם בעברית שעוזר לנהל את היום־יום בבית הספר: מערכת שעות, שיעורי בית,
מבחנים, ציונים ותזכורות — עם סיכום יומי שנשלח אוטומטית כל בוקר.

עובד בשני מצבים:

- **בסיסי** — תפריטים, קיצורי כתיבה ותזכורות. בלי מפתחות, בלי עלות.
- **סוכן AI** — שיחה חופשית בעברית, גישה לכל הנתונים שלך, יצירת מצגות
  ואקסל, וחיבור למייל/יומן/זום דרך שרת MCP.

---

## ⚠️ לפני הכול: אבטחת הטוקן

אם הטוקן של הבוט נחשף אי פעם (בצ'אט, בצילום מסך, בקוד) — **החלף אותו**:

1. `@BotFather` → `/revoke` → בחר את הבוט → קבל טוקן חדש.
2. שים את הטוקן החדש בקובץ `.env` בלבד.

הטוקן אף פעם לא נכנס ל-git: `.env` מופיע ב-`.gitignore`.

## שני המצבים

### בסיסי (ברירת מחדל)
תפריטים, קיצורי כתיבה, תזכורות וסיכום יומי. דורש רק טוקן טלגרם.

### סוכן AI
הוסף `ANTHROPIC_API_KEY` ל-`.env` והבוט הופך לסוכן: אפשר לדבר איתו חופשי,
הוא קורא וכותב בנתונים שלך דרך כלים, ויודע ליצור קבצים.

```
מה יש לי מחר?
תרשום לי לסכם פרק 5 בביולוגיה עד יום שני
תכין לי מצגת על פוטוסינתזה
מה הממוצע שלי במתמטיקה?
```

הכלים שהסוכן מפעיל על הנתונים: `get_agenda` · `list/add_homework` ·
`complete_homework` · `list/add_exam` · `list/add_grade` ·
`get_schedule` · `set_schedule_day` · `add/list_reminder`.

**יצירת קבצים** — הסוכן כותב קוד פייתון בסביבת ההרצה של Anthropic ומייצר
`.pptx` · `.xlsx` · `.docx` · `.pdf`, והבוט שולח אותם בטלגרם כמסמך.
בהפעלה הבוט בודק אילו סקילים זמינים בחשבון; אם אין — התכונה מכובה בשקט.

**חיבור למייל, יומן וזום** — דרך `MCP_SERVER_URL`. כל שרת MCP מתאים
(למשל Zapier MCP, שמביא איתו את החשבונות שחיברת שם). הכלים של השרת
מגיעים אוטומטית לסוכן, בלי לכתוב אינטגרציה לכל שירות בנפרד.

> חשוב: המפתח והכתובת יושבים ב-`.env` אצלך. הבוט הוא הצד היחיד שמחזיק אותם.

## התקנה והרצה

דרוש Node.js 18.17 ומעלה (נבדק על Node 22).

```bash
npm install    # תלות אחת: ה-SDK של Anthropic
npm run setup  # אשף שמגדיר הכול ומריץ אבחון
npm start
```

`npm run setup` שואל על כל מפתח, אומר מאיפה להביא אותו, בודק שהערך נראה תקין,
כותב `.env` תקין (UTF-8 בלי BOM, שומר על מפתחות קיימים) ומריץ `doctor` בסוף.
Enter על שאלה = לדלג או להשאיר את הערך הקיים.

להגדרה ידנית: `cp .env.example .env` ועריכה בעורך טקסט.

בדיקות (רצות אופליין, בלי רשת):

```bash
npm test
```

### 🩺 הבוט לא מגיב?

```bash
npm run doctor
```

הכלי בודק בסדר הזה: האם יש טוקן · האם טלגרם מקבל אותו · האם מוגדר webhook
שחוסם את ה-polling · האם רץ מופע אחר · כמה הודעות ממתינות שאף אחד לא קרא ·
ואם הוגדר מוח AI — האם המפתח תקף ואם שרת ה-MCP באמת נענה.

הסיבה השכיחה ביותר: **אף תהליך לא רץ.** בוט טלגרם עונה רק כש-`npm start` פעיל —
ברגע שסוגרים את החלון או שהמחשב נכבה, הבוט מפסיק לענות. להרצה קבועה ראה
[הרצה קבועה בשרת](#הרצה-קבועה-בשרת).

אם מוגדר webhook שחוסם:

```bash
npm run doctor -- --fix
```

### הבוט איטי או מדלג על הודעות?

בלוג מופיעים `fetch failed` / `UND_ERR_CONNECT_TIMEOUT` וניסיונות חוזרים.
זו תקלת רשת בין המחשב לטלגרם, לא באג בבוט. `npm run doctor` בודק IPv4 מול IPv6
בנפרד, מודד זמן תגובה ומריץ חמש קריאות רצופות כדי למדוד יציבות.

הסיבה השכיחה: הספק מפרסם כתובת IPv6 שלא באמת עובדת. Node מנסה אותה ראשונה,
נתקע עד שנגמר הזמן, ורק אז נופל ל-IPv4. הבוט מעדיף IPv4 אוטומטית
(`dns.setDefaultResultOrder('ipv4first')` + Happy Eyeballs). לביטול: `PREFER_IPV4=0`.

אם גם IPv4 נכשל או איטי מאוד — נסה רשת אחרת, כבה זמנית אנטי-וירוס שסורק תעבורה
מוצפנת, או הפעל VPN.

### משתני סביבה

| משתנה | ברירת מחדל | תיאור |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | — | **חובה.** הטוקן מ-@BotFather |
| `TZ_NAME` | `Asia/Jerusalem` | אזור זמן לתאריכים, תזכורות וסיכום יומי |
| `DATA_FILE` | `./data/schoolboost.json` | מיקום קובץ הנתונים |
| `LOG_LEVEL` | `info` | `debug` / `info` / `warn` / `error` |
| `PREFER_IPV4` | `1` | העדפת IPv4 בחיבור לטלגרם. `0` מחזיר את ברירת המחדל של Node |
| `ANTHROPIC_API_KEY` | — | מפעיל את סוכן ה-AI. בלעדיו הבוט עובד במצב בסיסי |
| `AI_MODEL` | `claude-opus-5` | המודל שמפעיל את הסוכן |
| `AI_EFFORT` | `medium` | עומק חשיבה: `low` … `max`. גבוה יותר = איטי ויקר יותר |
| `AI_FILES` | `1` | יצירת מצגות/אקסל/מסמכים. `0` לכיבוי |
| `MCP_SERVER_URL` | — | שרת MCP עם החשבונות המחוברים (מייל, יומן, זום…) |
| `MCP_SERVER_NAME` | `connectors` | שם השרת כפי שהמודל רואה אותו |
| `MCP_SERVER_TOKEN` | — | טוקן הרשאה לשרת ה-MCP, אם נדרש |
| `TELEGRAM_API_BASE` | `https://api.telegram.org` | לשימוש מתקדם (בדיקות / Bot API server עצמאי) |

## מה הבוט יודע לעשות

### 📅 מערכת שעות
עריכה יום־יום בהדבקה אחת:

```
08:00 מתמטיקה
08:50 אנגלית
09:45 היסטוריה
```

אפשר גם בלי שעות — רק שמות מקצועות לפי הסדר. יש תצוגת שבוע, היום ומחר.

### 📝 שיעורי בית
הוספה עם מקצוע, מטלה ותאריך הגשה. הרשימה ממוינת לפי דחיפות
(🔴 היום/באיחור · 🟠 מחר · 🟢 בהמשך), סימון כבוצע בלחיצה, וארכיון של מה שהושלם.

### 🎯 מבחנים
תאריך + חומר למבחן, עם ספירה לאחור ("בעוד 3 ימים", "🔥 היום!").

### 💯 ציונים
ממוצע משוקלל לפי מקצוע וממוצע כללי.

### ⏰ תזכורות
תזכורת חד־פעמית בזמן מדויק. המתזמן בודק כל 30 שניות ושולח בזמן.

### ☀️ סיכום יומי
כל בוקר בשעה שהגדרת: שיעורים היום, מטלות דחופות ומבחנים קרובים.
בסופ"ש בלי שיעורים ובלי מטלות — הבוט שותק במקום להעיר אותך.

### עמידות
- שגיאה בעדכון בודד לא מפילה את הלולאה.
- תקלת רשת חולפת → ניסיון חוזר אוטומטי, כדי שתשובה למשתמש לא תיעלם.
  ניסיון חוזר רק על תקלות שקרו *לפני* שהבקשה נשלחה, כדי לא לשלוח הודעה כפולה.
- ניתוקי polling → השהיה מצטברת עד 8 שניות (תקרה נמוכה בכוונה: בזמן ההמתנה הודעות לא נאספות).
- תשובה שאינה JSON (פרוקסי, רשת אורחים) → שגיאה ברורה במקום קריסת פענוח.
- `409` (שני מופעים / webhook פעיל) → הסרת webhook והמשך.
- `429` → המתנה לפי `retry_after`.
- `403` (המשתמש חסם) → הבוט מפסיק לשלוח לצ'אט הזה.
- קובץ נתונים פגום → מתחילים מאפס במקום לקרוס.
- כל טקסט מהמשתמש עובר escaping לפני שליחה ב-HTML.

## הרצה קבועה בשרת

**pm2:**
```bash
npm install -g pm2
pm2 start src/index.js --name schoolboost
pm2 save && pm2 startup
```

**systemd** (`/etc/systemd/system/schoolboost.service`):
```ini
[Unit]
Description=SchoolBoost Telegram Bot
After=network-online.target

[Service]
Type=simple
WorkingDirectory=/opt/SchoolBoost
ExecStart=/usr/bin/node src/index.js
Restart=always
RestartSec=5
User=schoolboost

[Install]
WantedBy=multi-user.target
```

```bash
sudo systemctl enable --now schoolboost
journalctl -u schoolboost -f
```
