# סרטון פרסומת — סגנון Reels / TikTok

סרטון פרסומת אנכי בעברית (RTL), בנוי ב-[Remotion](https://remotion.dev).
פורמט: **1080×1920, 30fps, ~12.9 שניות** — מתאים ל-Instagram Reels, TikTok ו-Stories.

## מבנה הסרטון

| # | שקופית | טקסט | אפקט |
|---|--------|------|------|
| 1 | `SceneHook` | "מה הסוד..." | טקסט קופץ מילה־אחר־מילה + טבעת אור מתפרצת |
| 2 | `SceneGallery` | "של הסרטונים שמושכים הכי הרבה עיניים?" | גלריית עבודות שנעה בפרספקטיבה תלת־ממדית |
| 3 | `SceneResults` | "עריכת וידאו מקצועית ברמה הגבוהה ביותר!" | כרטיסי מדדים עם מונים רצים |
| 4 | `SceneBrand` | שם המותג + הסלוגן | טבעות ניאון מסתובבות וסמל נגן |
| 5 | `SceneCta` | "רוצים סרטון כזה לעסק שלכם?" | כפתור פועם + "דברו איתי בפרטי 📩" |

המעברים בין השקופיות הם `slide` ו-`fade` דרך `TransitionSeries`, באורך 10 פריימים כל אחד.
הרקע (`Backdrop`) יושב **מתחת** ל-`TransitionSeries` כך שהגרדיאנט זורם ברציפות בזמן שהתוכן מתחלף.

## שינוי הפרטים שלכם

כמעט כל מה שצריך לשנות נמצא בקובץ אחד — [`src/config.ts`](src/config.ts):

```ts
export const BRAND = {
  name: "STUDIO CUT",                        // ← שם העסק שלכם
  tagline: "מערכת העריכה שדואגת לתוצאות",
  handle: "@studiocut",                      // ← היוזר באינסטגרם
};

export const METRICS = [
  { value: 96,  suffix: "%", label: "מעורבות" },
  { value: 3.2, suffix: "x", label: "יותר צפיות" },
  { value: 91,  suffix: "%", label: "שימור צופים" },
];
```

> המדדים הם ערכי דוגמה. החליפו אותם במספרים אמיתיים שלכם לפני פרסום.

באותו קובץ נמצאים גם הצבעים (`COLORS`) ואורך כל שקופית בפריימים (`SCENE_DURATIONS`) —
30 פריימים = שנייה אחת. משך הסרטון הכולל מחושב אוטומטית ומקזז את המעברים.

### החלפת כרטיסי הגלריה בעבודות אמיתיות

`CreativeCard` מצייר כרטיס מופשט. כדי להשתמש בעבודות שלכם, שימו קבצים ב-`public/`
והחליפו את גוף הקומפוננטה ב:

```tsx
<CanvasImage src={staticFile("works/reel-1.jpg")} style={{ width, height }} />
```

## הרצה

```bash
npm i
npx remotion studio        # תצוגה מקדימה חיה בדפדפן
npx remotion render AdVideo out/ad-video.mp4
```

כל שקופית רשומה גם בנפרד בתיקיית `Scenes` ב-Studio, כך שאפשר לערוך או לייצא אותה לבד:

```bash
npx remotion render Scene5-Cta out/cta.mp4
```

# `PitchUpgrade` — עריכה משודרגת לסרטון פיץ' אישי

הרכב שני בפרויקט (`src/pitch/`): לוקח סרטון "דבר אל המצלמה" קיים ובונה עליו
עריכה מלאה — כתוביות מסונכרנות, קלפים מעוצבים וסטינגרים ממותגים.
**1080×1920, 30fps, ~18 שניות**, בפלטה סגול־אינדיגו עם זהב.

## הרעיון המרכזי: ציר זמן משותף

ציר הזמן של הפלט **זהה** לציר של קובץ המקור. פס הקול רץ ברצף אחד
(`<Audio>` נפרד), הצילום רץ ברצף אחד ומושתק, והקלפים המעוצבים הם שכבות
אטומות שמכסות אותו בחלונות מסוימים. אין שום מיפוי זמנים ולכן אי אפשר
לאבד סנכרון בין הקול, התמונה והכתוביות.

בסוף נוסף זנב מעוצב (`OUTRO_TAIL`) אחרי שהדיבור נגמר.

## חומר הגלם

שימו את קובץ הווידאו ואת פס הקול שחולץ ממנו כאן:

```
public/source/pitch.mp4
public/source/pitch-audio.m4a
```

התיקייה ב-`.gitignore` — חומר גלם אישי לא נדחף לגיט. לחילוץ פס הקול:

```bash
ffmpeg -i public/source/pitch.mp4 -vn -c:a aac -b:a 128k public/source/pitch-audio.m4a
```

## כתוביות

הטקסטים והתזמונים יושבים ב-[`src/pitch/timeline.ts`](src/pitch/timeline.ts)
במערך `CUES`. כל כתובית נחלקת למילים, והמילה הפעילה מודגשת בזהב וקופצת —
המילים מחולקות באופן אחיד לאורך חלון הכתובית.

> **חשוב:** התמלול לא הופק מזיהוי דיבור אלא **נקרא מהכתוביות הצרובות של
> קובץ המקור** (בסביבה שבה נבנה הפרויקט לא הייתה גישה למנוע תמלול).
> הכתיב תוקן לעברית תקנית. כדאי לעבור על התזמונים ולדייק אותם באולפן.

לתזמון אמיתי ברמת מילה, ראו את [סקיל התמלול](../.agents/skills/remotion-captions/transcribe-captions.md)
והריצו `@remotion/install-whisper-cpp` בסביבה עם גישה לרשת.

## הסתרת הכתוביות הצרובות

בקובץ המקור יש כתוביות וגרפיקות **צרובות בפיקסלים** שאי אפשר להסיר.
שתי מערכות מטפלות בזה:

1. **פס הכתוביות** (`CaptionBand`) — פאנל עם `backdrop-filter: blur(34px)`
   שיושב בדיוק על הרצועה שבה יושבות הכתוביות הצרובות (59%–76% מגובה
   הפריים) ומוחק אותן.
2. **הקלפים המעוצבים** (`CARDS`) — מכסים את החלונות שבהם המקור מציג
   גרפיקה משלו: הרשת האדומה, הקטע הכהה עם הטקסט הצהוב, מוקאפ הטלפון
   ושני אפקטי המעבר.

**לכן כל המעברים הם חיתוכים חדים ולא דהיות.** כל דהייה — בכניסה או
ביציאה — חושפת פריים או שניים של הגרפיקה הצרובה שמתחת. אם משנים תזמון,
צריך לוודא שהקלף והפאנל **משיקים בדיוק** ולא נשאר ביניהם פער.

> אם יש לכם את הצילום הגולמי **בלי כתוביות צרובות**, החליפו את
> `public/source/pitch.mp4` — אפשר יהיה להקטין את הפאנל, להחזיר דהיות
> רכות ולוותר על חלק מהקלפים.

## הרצה

```bash
npx remotion render PitchUpgrade out/pitch-upgrade.mp4
```

פרטי היוצר לקלף הסיום ולסטינגרים נמצאים ב-`CREATOR` בתוך
[`src/pitch/theme.ts`](src/pitch/theme.ts).

# `ReelVideo` — ריל שמחבר שני צילומים

הרכב שלישי (`src/reel/`): מחבר שני קליפים נפרדים לסרטון אחד עם
כתוביות, הנפשות, מוזיקה ועיצוב סאונד. **1080×1920, 30fps, 19 שניות.**

## המבנה

| זמן | מה קורה |
|-----|---------|
| 0.00–1.50 | קלף פתיח "למה לבחור דווקא בי?" |
| 1.50–2.70 | `part1.mp4` + כתוביות |
| 2.70–4.25 | קלף "אומנם אני בן 15" |
| 4.25–6.30 | `part1.mp4` + כתוביות |
| 6.30–7.00 | סטינגר ממותג בין שני הקליפים |
| 7.00–16.35 | `part2.mp4` + כתוביות |
| 16.35–19.00 | קלף סיום והנעה לפעולה |

הקשר בין שני הקליפים נבנה משלושה דברים: פס התקדמות אחד שרץ לאורך כל
הסרטון, תגי פרק (`01 השאלה` / `02 התשובה`) שמופיעים בתחילת כל קטע,
וסטינגר ממותג בנקודת החיבור.

## אודיו

**חשוב:** הרינדור של Remotion מנגן `m4a` אבל **לא** `wav` — קובץ wav
יוצא דומם לגמרי בלי שום שגיאה. לכן כל נכס אודיו מומר ל-m4a
ב-`scripts/lib/audio.mjs`.

שני סקריפטים מייצרים את כל האודיו, בלי תלות בשום ספרייה חיצונית:

```bash
node scripts/make-audio.mjs     # מוזיקה ואפקטים — מסונתזים מאפס
node scripts/prepare-clips.mjs  # רצועות הדיבור, מנורמלות
```

- `make-audio.mjs` מסנתז פס מוזיקה (לה מינור, 120 BPM, Am·F·C·G) עם
  מעטפת עוצמה שמנמיכה את המוזיקה מתחת לדיבור ומרימה אותה בפתיח,
  בסטינגר ובסיום. בנוסף הוא מייצר `whoosh`, `impact`, `riser`,
  `sub-drop`, `tick` ו-`pop`.
- `prepare-clips.mjs` מחלץ את הדיבור משני הקליפים ומביא אותם לאותה
  עוצמה. זה הכרחי: `part1` הוקלט חזק עד כדי גזירה ו-`part2` שקט פי
  עשרים. הסקריפט מיישר את שניהם ל-RMS דיבור זהה ומגביל רכות את השיאים.

מיקום האפקטים מוגדר במערך `SFX` ב-[`src/reel/timeline.ts`](src/reel/timeline.ts).
בכל החלפת כתובית מתנגנת נקישה רכה.

## כתוביות

- **חלק 1** — `CUES_PART1`. נקראו מהכתוביות הצרובות של הקליפ ותוקנו
  לכתיב תקני, ומוצגות בפאנל מטושטש שמסתיר את המקוריות.
- **חלק 2** — `CUES_PART2`. הקליפ גולמי ואין בו כתוביות צרובות, ולכן
  הכתוביות שם נקיות בלי פאנל.

> ⚠️ **הטקסט של חלק 2 חסר.** חלונות הזמן כבר מדויקים — הם אותרו
> אוטומטית מעוצמת פס הקול — אבל אין בסביבה הזו מנוע תמלול ואי אפשר
> לקרוא את המילים משום מקום. אין להמציא טקסט. מלאו את שמונת המחרוזות
> ב-`CUES_PART2` והכתוביות יעבדו מיד.

## הרצה

```bash
node scripts/make-audio.mjs && node scripts/prepare-clips.mjs
npx remotion render ReelVideo out/reel.mp4
```

## פונטים

שני ההרכבים משתמשים ב-**Heebo** (משקלים 400/700/900). קבצי ה-TTF שמורים
ב-`public/fonts/` ונטענים דרך `@remotion/fonts` — כך שהרינדור אינו תלוי
ברשת ויוצא זהה בכל סביבה.

## רינדור בסביבה בלי הורדת דפדפן

Remotion מוריד Chrome Headless Shell בהרצה הראשונה. אם ההורדה חסומה,
אפשר להצביע על Chromium מקומי:

```bash
REMOTION_BROWSER_EXECUTABLE=/path/to/headless_shell npx remotion render AdVideo out/ad-video.mp4
```

`remotion.config.ts` קורא את משתנה הסביבה הזה אם הוא מוגדר.
