# Agent Editor & Layout — סוכן עורך ומעצב

**קובץ מימוש:** `src/agents/editor.mjs`

## תפקיד

לחבר את טקסט המקור יחד עם 50 האיורים והכתוביות לכדי ספר שלם, רציף ומעוצב
ברמת גימור גבוהה.

## קלט

| מקור | תיאור |
| --- | --- |
| עץ המקור המפוענח | הטקסט המקורי, verbatim |
| storyboard מסוכן הוויזואל | 50 עמודים + איורים + כתוביות |
| `layout` | פרמטרי עיצוב, מתעדכנים ע"י סוכן הביקורת |

## תפוקה

`dist/book.html` — קובץ אחד, עצמאי, RTL, מותאם לנייד ולהדפסה.

## מה הוא מרכיב

- **כריכה** עם כותרת, תת-כותרת ושורת "מה מקבלים".
- **תוכן עניינים** אינטראקטיבי (רשימה או כרטיסים).
- **פותח פרק** עם תג LEVEL, שורת וו (hook) ורצועת נתונים: עמודים / דקות / איורים.
- **גוף העמוד** — טיפוגרפיה עברית, היררכיה, מידת שורה מבוקרת.
- **רכיבי תוכן:** ציטוט, pull-quote, קלאוט "שים לב", קלאוט "כלל",
  טבלאות גלילות, צ׳ק-ליסטים עם תיבות סימון, כרטיסי ארנק/בוס/יום.
- **HUD התקדמות קריאה** דביק בראש המסך.
- **כותרת תחתונה** עם מספור עמודים, ו-`@media print` לעמוד-לעמוד.

## אילוצים

- כל מחרוזת טקסט מוזרמת **כפי שהיא**. עיצוב = מעטפת, לא ניסוח.
  הדגשת מספרים (`5,000 ₪`) עוטפת תווים קיימים, לא משנה אותם.
- בכל build רץ אימות `verifyBuild()`: 525 מקטעי טקסט חייבים להימצא verbatim.
  build שנכשל — עוצר את הלולאה.

## פרמטרי העיצוב שסוכן הביקורת יכול לשנות

| פרמטר | השפעה |
| --- | --- |
| `scale` / `measure` / `density` | גודל טקסט, אורך שורה, אוויר |
| `hooks` | שורת פתיחה בראש פרק |
| `pullQuotes` | הבלטת משפט מפתח אחד לפרק |
| `accentRotation` | צבע ייחודי לכל פרק |
| `pageBadges` / `runningFooter` | מיקום בפרק, מספור עמודים |
| `chapterHud` / `microCopy` | נתוני פרק, "מה מקבלים" בכריכה |
| `tocCards` | תוכן עניינים ככרטיסים |
| `endMarkers` | טיזר לפרק הבא |
| `paragraphBeats` | שבירה ויזואלית של רצף פסקאות |
