# Agent Teen Reviewer — סוכן ביקורת נוער (13–18)

**קובץ מימוש:** `src/agents/reviewer.mjs`

## תפקיד

לבחון את הספר המוגמר מנקודת מבט של נער/ה, ולענות על שלוש שאלות:

1. **מעניין?**
2. **נראה טוב?**
3. **מרגיש שווה 20 ₪?**

## חוק הברזל

> הסוכן לא מוחק ולא משנה את תסריט הליבה ואת התוכן הפיננסי.
> אם משהו "משעמם" או "כבד" — הוא מבקש מסוכן העיצוב לשנות ניסוח-מסגרת,
> סטיילינג או layout בלבד.

**איך זה נאכף בקוד, ולא בהבטחה:**

- כל בקשה יוצאת מסווגת ל-`style` / `layout` / `framing` / `visual`.
  `assertDirectives()` זורק חריגה על כל סיווג אחר.
- בכל סבב `verifyBuild()` מוודא ש-525 מקטעי טקסט המקור נמצאים verbatim בספר.
  אם מקטע נעלם — הלולאה נעצרת עם `IRON RULE VIOLATION`.
- לסוכן הביקורת אין בכלל ממשק שמאפשר לגעת בטקסט. הוא מקבל HTML לקריאה
  ומחזיר רשימת בקשות עיצוב.

## מדדים שהוא לוקח מהספר הבנוי

מספר איורים · כתוביות · גיוון ארכיטיפים · אחוז עמודים עם דמות ·
הרצף הארוך ביותר של פסקאות ללא הפסקה ויזואלית · מספר צ׳ק-ליסטים וטבלאות ·
קלאוטים · זמן קריאה · מספור עמודים · מיקרו-קופי בכריכה.

## סף אישור

```
overall  >= 88     ממוצע שלושת הצירים
weakest  >= 80     אף ציר לא נשאר מאחור
directives == 0    אין בקשה פתוחה
```

רק כששלושתם מתקיימים הוא מוציא את המשפט:

> **100% מוכן לקריאה**
