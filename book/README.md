# 5,000 ₪ — מערכת שלושת הסוכנים

מערכת אוטונומית של שלושה סוכנים שמייצרת ספר דיגיטלי מאויר בן 50 עמודים
לבני ובנות נוער (13–18), מתוך טקסט מקור נתון — ורצה בלולאה עד לאישור סופי
של סוכן ביקורת הנוער.

```
npm start      # מריץ את הלולאה ובונה את הספר
npm run bundle # אורז קובץ אחד עצמאי לגמרי, עם הגופנים בפנים
npm test       # בדיקות קבלה על התוצר
```

## הסוכנים

| # | סוכן | תפקיד | מימוש | מפרט |
| --- | --- | --- | --- | --- |
| 1 | **Visual** | 50 איורים + 50 כתוביות + 50 פרומפטים | `src/agents/visual.mjs` | [spec](agents/01-visual.md) |
| 2 | **Editor & Layout** | הרכבת הספר המעוצב | `src/agents/editor.mjs` | [spec](agents/02-editor.md) |
| 3 | **Teen Reviewer** | ביקורת מגיל 13–18 ואישור סופי | `src/agents/reviewer.mjs` | [spec](agents/03-reviewer.md) |

## הלולאה

```
                 ┌──────────────────────────────────────────┐
                 │                                          │
   טקסט מקור ──▶ Visual ──▶ Editor ──▶ Teen Reviewer ──┐    │
   (חתום)                       ▲                       │    │
                                │                       │    │
                                └── הנחיות עיצוב בלבד ◀─┘    │
                                                             │
                          "100% מוכן לקריאה" ──▶ יציאה ◀─────┘
                          או: תום תקציב 120 דקות
```

בכל סבב: הוויזואלי מתכנן מחדש את 50 העמודים לפי הכיוון האמנותי העדכני,
העורך מרכיב את הספר לפי פרמטרי העיצוב העדכניים, וסוכן הביקורת מנקד
שלושה צירים — **מעניין? / נראה טוב? / שווה 20 ₪?** — ומחזיר עד 4 בקשות.
הלולאה נעצרת רק כששלושת הצירים עוברים את הסף ואין בקשה פתוחה.

## חוק הברזל — נאכף בקוד

סוכן הביקורת לא מוחק ולא משנה את תסריט הליבה ואת התוכן הפיננסי:

1. **סיווג בקשות** — כל בקשה חייבת להיות `style` / `layout` / `framing` / `visual`.
   `assertDirectives()` זורק חריגה על כל סיווג אחר.
2. **חותם תוכן** — 525 מקטעי טקסט מוטבעים ב-SHA-256 לפני הסבב הראשון.
3. **אימות בכל build** — `verifyBuild()` מוודא שכל 525 המקטעים נמצאים verbatim
   בספר הבנוי. אם אחד חסר, הלולאה נעצרת עם `IRON RULE VIOLATION`.

## תוכן ורגולציה

הספר עוסק בחינוך פיננסי ולא במתן ייעוץ. ההסתייגויות שבמקור — שהשקעות אינן
מכונת כסף מובטחת, שהמספרים הם דוגמה מתמטית ולא הבטחת תשואה, שהחלטות
משמעותיות בגיל צעיר נעשות עם הורה/אפוטרופוס, ושחלים חוקי עבודה על בני נוער —
עוברות לספר verbatim ומקבלות בו קלאוט ייעודי.
