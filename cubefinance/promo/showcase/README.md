# CubeFinance — סרטון תדמית 30 שניות (16:9, 1920×1080)

## מה יש בתיקייה

| קובץ | מה זה |
|---|---|
| `cubefinance-showcase.mp4` | הסרטון המוגמר: H.264, 30fps, קריינות ומוזיקה |
| `scene.html` | כל האנימציה, כ-HTML/CSS/JS אחד. כל פריים מחושב לפי זמן (`renderAt(t)`) |
| `screens/` | המסכים האמיתיים מתוך הקלטת המסך של האפליקציה (נתוני דוגמה), בלי שורת המצב ומקשי הניווט |
| `logo.svg`, `fonts/` | הלוגו וגופן Heebo (רישיון OFL) |
| `music.js` | המוזיקה. נכתבה בקוד ומסונתזת, בלי קטעים מוכנים, ולכן מותרת לכל פרסום |
| `voiceover.mp3` | הקריינות (ElevenLabs, הקול Nimrod, מודל eleven_v4) |
| `mix.sh` | מציב כל משפט קריינות על הסצנה שלו ומנמיך את המוזיקה מתחת לקול |
| `render.js` | מרנדר פריימים (או תמונות בודדות לבדיקה) עם Playwright |
| `make.sh` | בונה הכול מחדש |
| `stills/` | תמונה מכל סצנה |

## איך עורכים

- **טקסט או כותרת:** ב-`scene.html`, בבלוקים `t1` עד `t6`.
- **תזמון:** הזמנים של כל סצנה כתובים בתוך `renderAt`, ותנועת הטלפון בפונקציה `kf(...)`.
- **מסך אחר:** מחליפים קובץ ב-`screens/`. הכרטיסים שיוצאים מהמסך מוגדרים לפי פיקסלים ב-`CARDS`.
- **קריינות חדשה:** מחליפים את `voiceover.mp3` ומעדכנים את זמני החיתוך ב-`mix.sh`.

## איך מרנדרים מחדש

צריך Node, Playwright (עם Chromium) ו-ffmpeg:

```sh
npm i -D playwright && npx playwright install chromium
./make.sh
```
